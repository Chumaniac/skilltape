SkillTape / 使用指南

从第一次打开，到保存结果

把本地任务的输入、执行过程、结果与验证凭据放在一起。

01

打开「本地任务」，用示例填写对账数据，核对差异并导出输入 JSON。页面计算与持久化结果是本地操作，不代表已经获得执行凭据。

02

用下方命令从导出的 JSON 创建任务材料。检查输入，再显式加 --yes 执行。输出目录必须是全新目录，不能覆盖旧结果。

03

在 Console 中选择运行目录，查看 Capture、Compile、Lint、Verify、Export 结果以及原始 Receipt。

这件工具擅长什么

保留输入快照、结果哈希和原始 Receipt。复现依赖明确的沙箱边界；检查页面不会执行任意任务。

你的资料放在哪里

桌面默认 ~/Library/Application Support/SkillTape/workspace；通过「选择工作区」打开已有运行目录。CLI 写入你指定的新输出目录。

退出前保存当前草稿。迁移电脑时先正常退出，确认没有在途任务，再备份完整私人数据目录；不要覆盖唯一原件。

需要额外准备的条件

Windows 支持查看和输入准备，Replay/Verify 不支持时会明确拒绝。macOS/Linux 的执行需要系统沙箱；没有沙箱时不会降级成无隔离执行。Receipt 证明特定输入与结果的验证记录，不承诺任务具有任意业务正确性。

遇到错误，保留原记录，先用合成示例复现；不要上传访问文件、真实原稿或完整环境配置。源码与更多说明位于 github.com/Chumaniac/skilltape-app。
