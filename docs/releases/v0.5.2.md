# SkillTape 0.5.2

This patch packages the reviewed Console inventory and export changes from the current main source. Directory-entry type checks preserve existing link rejection, identifier filtering, snapshot ownership and capacity guards. The matching CodeQL review and individual dispositions remain in docs/security/codeql-path-audit.md; this release is not an independent security certification.

CLI, API and Console retain one source/version/target identity. The native release workflow builds Linux x86_64, macOS Intel, macOS Apple Silicon and Windows archives with checksums, SBOM and provenance; Apple Silicon also includes a relocatable application ZIP. Windows Replay/Verify remain unavailable without the supported system sandbox.

The macOS application is ad-hoc signed and is not Apple notarized. Minimum system compatibility comes from the built binary manifest. Existing workspaces and successful Captures/Receipts are not migrated, executed or uploaded by installation.

All prior tags, releases and download URLs, including v0.5.1, remain available.
