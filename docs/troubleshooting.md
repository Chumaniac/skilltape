# 排错

| 现象 | 处理 |
|---|---|
| 打不开本机页面 | 确认启动窗口仍在；查看终端给出的地址。桌面版端口 19001 被占用时先核对原服务，不能直接结束未知进程。 |
| 缺少依赖 | 按 README 的锁文件安装命令重新检查；不要混用其他项目的虚拟环境或全局模块。 |
| 桌面程序被系统拦截 | 本地构建使用临时签名，不是 Apple 公证分发。校验发布 SHA-256 与来源；不确定时选择源码构建。不提供关闭系统安全保护的步骤。 |
| 保存冲突 | 先保留当前草稿，再重新读取最新版本，核对后显式保存。 |
| 原数据不兼容 | 停止写入并备份；先运行升级检查。不能删除原库或反复重试覆盖成功记录。 |
| 外部模型/设备不可用 | 核对对应能力条件；保留错误。没有真实连接不显示虚构结果。 |

环境检查/帮助：

```sh
./target/release/skilltape starter new reconcile --request /path/request.json --output /path/new-inputs
./target/release/skilltape starter run /path/new-inputs --output /path/new-run --yes
```

提交 Issue 请给出操作系统、版本、合成输入、预期与实际效果；不要附访问文件、令牌或真实业务数据。
